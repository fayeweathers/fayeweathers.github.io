نبذة عني

أنا زياد، طالب هندسة ذكاء اصطناعي ومطور. ما أكتفي بالجانب النظري، بل أبني وأطلق مشاريعي بنفسي مثل المواقع، بوتات ديسكورد، أدوات OSINT، وتطبيقات الذكاء الاصطناعي اللي الناس فعلاً تستخدمها.

تطوير الويب

أبني مواقع نظيفة وسريعة، بتجربة استخدام سلسة ومريحة.

بوتات ديسكورد والأتمتة

بوتات إدارة وحماية، وأتمتة للمهام المتكررة لتوفير الوقت والجهد.

OSINT والأمن السيبراني

جمع المعلومات من المصادر المفتوحة، وتحليل النطاقات، وبناء أدوات استطلاع أخلاقية.

الذكاء الاصطناعي وتدريب النماذج

تدريب النماذج على بيانات مخصصة وتحسين أدائها، وبناء مساعدين أذكياء.

التقنيات اللي أستخدمها

JavaScript Node.js Discord.js Python HTML CSS C C++ Linux Git PyTorch APIs

بعيداً عن الأدوات، أشتغل على أبحاث OSINT، وأدرب نماذج ذكاء اصطناعي على بيانات مخصصة، وأتمت المهام المتكررة عشان تشتغل لحالها. كل مشروع أبدأه يطلع من مشكلة حقيقية، وينتهي بأداة يستخدمها الناس.

اشتغلت مع عملاء حقيقيين وسلّمت مشاريع كاملة، وما زلت أطلق شي جديد باستمرار.
