About Me

أنا زياد — طالب هندسة ذكاء اصطناعي ومطوّر. لا أكتفي بالتعلّم فقط، بل أبني وأطلق أدوات حقيقية: منصات ويب، بوتات ديسكورد، أدوات OSINT، وأنظمة ذكاء اصطناعي تخدم مستخدمين فعليين.

تطوير الويب

واجهات نظيفة، أداء سريع، وتجربة استخدام مدروسة.

بوتات ديسكورد والأتمتة

إدارة، حماية، وأتمتة مهام متكررة داخل السيرفرات والأنظمة.

OSINT والأمن السيبراني

جمع المعلومات من مصادر مفتوحة، تحليل النطاقات، وأدوات استطلاع أخلاقية.

الذكاء الاصطناعي وتدريب النماذج

تدريب وتحسين نماذج تعلّم الآلة على بيانات مخصصة، وبناء مساعدين أذكياء.

الأدوات التي أعمل بها

JavaScript Node.js Discord.js Python HTML CSS C C++ Linux Git PyTorch APIs

خارج بناء الأدوات، أعمل على أبحاث OSINT وأدوات الاستطلاع الأخلاقي، وأدرّب وأحسّن نماذج تعلّم الآلة على بيانات مخصصة، وأؤتمت سير العمل المتكرر ليعمل تلقائياً بدل أن يُستهلك فيه الوقت. كل مشروع أبدأه ينطلق من مشكلة حقيقية، وينتهي بأداة يستخدمها الناس فعلاً.

نفّذت مشاريع لعملاء حقيقيين، وأواصل الإطلاق يومياً — كل مشروع خطوة للأمام.
